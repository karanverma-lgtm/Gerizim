## 2. Color Palette

The brand visual language uses a clean corporate high-trust color structure dominated by deep forest greens, vibrant lime/leaf green accents, dark charcoal text, and clean white backgrounds.

| Role | Color Name | Hex Code | Usage |
| :--- | :--- | :--- | :--- |
| **Primary Brand Color** | Forest Green | `#006633` | Company Title, Main Brand Headers, Logo Accent |
| **Secondary Accent** | Lime Green | `#90C126` / `#90C226` / `#99CA3C` | Taglines, Page Headings, Accents, Highlights |
| **Dark Neutral (Body Text)**| Dark Charcoal | `#3F3F3F` / `#404040` | Body Paragraphs, Lists, Detailed Descriptions |
| **Primary Neutral** | Pure Black | `#000000` | High-emphasis Subheadings, Pillar Categories |
| **Background / Light Neutral**| Pure White | `#FFFFFF` | Slide/Page Backgrounds, Card Container Fills |

## 4. Visual Elements & Layout Language

### Layout Structure
- **Format:** Landscape presentation format (16:9 aspect ratio, 3300x2550 rendered canvas).
- **Header Structure:** Top accent bar or prominent page header in Lime Green (`#90C226`).
- **Bullet Point / Icon Style:** Custom bullet markers (`` square/diamond pointers) for feature lists.
- **Card Grid Layouts:** 
  - 5-column grid layout for Core Services.
  - 2-column bulleted grid layout for Clientele lists.
  - 3 to 4-column geographic chip grid for Pan-India presence.
